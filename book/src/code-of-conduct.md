# Code of Conduct

This project is a place to make Rust and C++ work together, and its issues,
pull requests and reviews are for that work.

What is expected of everyone taking part:

* Be considerate, kind, constructive and helpful.
* Criticise code, designs and decisions, not the people behind them.
* No demeaning, discriminatory, harassing, hateful or sexualised behaviour,
  speech or imagery, and no personal attacks or threats.

Disagreement is welcome - technical arguments are how this project decides
things. Disrespect is not.

## Reporting problems

If you see someone behaving disrespectfully, and you are comfortable doing so,
address it directly with those involved. If that does not work, or the
behaviour is threatening or harassing, report it by opening an issue at
<https://github.com/Choochmeque/autocxx/issues>. A report which should not be
public can go to the maintainer instead, through the contact details on
<https://github.com/Choochmeque>.

Reports are read. What follows depends on the case, and may range from nothing
to removal from the project's spaces. Where action is taken the person it
concerns is told of the report and given a chance to respond first, except
where someone's safety is at stake.
